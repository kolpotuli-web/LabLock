Assessment Task CS-402

Task 1: Thread-Safe LRU Cache with Eviction Telemetry

Time Limit: 2.0s Memory Limit: 128MB

Implement an in-memory Least Recently Used (LRU) Cache data structure that satisfies O(1) average time complexity for both get and put operations.

Functional Specifications

  • LRUCache(int capacity): Initializes the data structure with positive capacity constraint.
  • int get(int key): Return the positive value corresponding to the key, or -1 if the key does not exist.
  • void put(int key, int value): Update existing key or insert key-value pair. When capacity is exceeded, evict the least recently accessed item.

Input Format Specification

["LRUCache", "put", "put", "get", "put", "get", "put", "get", "get", "get"] [[2], [1, 1], [2, 2], [1], [3, 3], [2], [4, 4], [1], [3], [4]]

Expected Output

[null, null, null, 1, null, -1, null, -1, 3, 4]

Compliance Requirements

All routines must execute without external library calls. Memory usage is tracked per allocation cycle.
