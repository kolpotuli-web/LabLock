Examination Setup

Local server configuration
Configuration is managed on the host machine.

For security, examination PINs, faculty credentials, model paths and allowed origins are configured in the server-side .env file. They are intentionally not editable or displayed in this browser dashboard.

01

Set examination access PIN

Configure EXAM_ACCESS_PIN in the backend environment file.

02

Set faculty authorization

Configure FACULTY_PIN and keep it private to authorized invigilators.

03

Restart and verify
